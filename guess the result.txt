'number' + 3 + 3  //результат буде "number33", цифри будуть приведені до типа даних string та відбудеться конкатенація (поєднання) рядків


null + 3  //результат буде 3, нал приведеться до числа 0


5 && "qwerty"  //результат - "qwerty", так як оператор && шукає першим значення false, а в нас обидва операнди - істинні, то повернеться другий операнд


+'40' + +'2' + "hillel"  //результат - "42hillel". +'40' та +'2' перетворюють значення в лапках на числа, далі ці числа сумуються, після чого має виконатись конкатенція з типом string, відповідно число 42 перетворюється на тип string та склеюється із "hillel"


'10' - 5 === 6;  //результат - false. '10' перетвориться на число, від нього відніметься 5, що в результаті дасть 5, а 5 не є еквівалентом 6


true + false  // результат - 1. true - це 1, false - це 0, 1 + 0 = 1


'4px' - 3 //результат - NaN, неможливо привести значення '4px' до типу number та виконати віднімання, тому результат - not a number


'4' - 3 //тут відбудеться приведення '4' до типу number та звичайна математична операція 4-3 = 1


'6' + 3 ** 0;  //результат '61', при використанні оператора плюс, якщо хоч один з операндів - рядок, то і інший буде приведено до того ж типу та відбудеться конкатенація. 3**0 - возведе 3 в 0 ступінь, тобто 1.


12 / '6'  //результат - 2. '6' стане числом 6


'10' + (5 === 6);  //результат '10false'. Вираз у дужках (5 === 6) - це false, адже 5 не еквівалентно 6, при використанні оператора плюс, якщо хоч один з операндів - рядок, то і інший буде приведено до того ж типу та відбудеться конкатенація


null == ''  //результат false, адже нал буквально не дорівнює пустим лапкам


3 ** (9 / 3);  //результат 27, це звичайний математичний вираз, в якому 3 потрібно привести в ступінь 9/3, тобто в третю


!!'false' == !!'true'  //результат true. так як обидва операнди, що є string, непорожні


0 || '0' && 1  //результат - 1. Оператор && має вищий пріоритет, тому спочатку буде виконано '0' && 1, тут буде шукатись перше false, а так як обидва операнда є true, то повернеться другий операнд - 1. Таким чином вираз набуде вигляду  0 || 1, так як оператор "або" шукає перший true, а 0 - це false, то в результаті повернеться 1, яка і є true


(+null == false) < 1;  //результат - false. Спочатку буде виконано вираз у дужках: +null буде приведено до цифрового значення, а саме до 0, далі порівняння 0 та false, що є true (бо false - це 0), так як  true=1, вираз 1 < 1 дасть нам false, адже 1 не менше за 1, а дорівнює 


false && true || true //результат - true.Оператор && має вищий пріоритет, тому спочатку буде виконано false && true, тут буде шукатись перше false, тож повернеться false. Таким чином вираз набуде вигляду  false || true так як оператор "або" шукає перший true, то в результаті і повернеться true


false && (false || true); //результат - false. За пріоритетом, спочатку буде виконано рівняння в дужках (false || true), тут буде шукатись перше true, тож повернеться true. Таким чином вираз набуде вигляду  false && true, і так як оператор "і" шукає перший false, то в результаті і повернеться false



(+null == false) < 1 ** 5; //результат - false. Спочатку буде виконано вираз у дужках: +null буде приведено до цифрового значення, а саме до 0, далі порівняння 0 та false, що є true (бо false - це 0), так як  true=1, а 1 в 5 ступені залишиться 1, то вираз  1 < 1 дасть нам false, адже 1 не менше за 1, а дорівнює
